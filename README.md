# Company Management System - Java OOP

🏢 **A simple company management system built with Java OOP principles.**

## 📌 Features

- **Employee Management**: Create employees with ID, Name, and Salary.
- **Salary Operations**: Increase salary by percentage, calculate annual salary.
- **Department Management**: Each department has a manager and up to 2 regular employees.
- **Project Management**: Assign employees to projects (challenge feature).
- **Salary Report**: Calculate total monthly salary for department (manager + employees).

## 🧱 Project Structure

| Class | Description |
|-------|-------------|
| `Employee` | Handles employee data and operations |
| `Department` | Manages department and employees |
| `Project` | Manages projects and assigned employees |
| `CompanyApp` | Main class to run the application |

## 🚀 How to Run
